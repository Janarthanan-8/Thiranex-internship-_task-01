# Personal Portfolio Website

A full-stack personal portfolio website created as part of the Thiranex Full Stack Internship.

## Features

- Personal introduction and about section
- Skills showcase
- Projects section
- Contact section
- Responsive design for mobile and desktop
- Backend server for handling application data

## Technologies Used

- HTML
- CSS
- Node.js
- Express.js
- MongoDB

1. Download or clone this repository.
2. Extract `janarthanan-portfolio.zip`.
